# US5 Validation - Coffee Name and Price Display

## Steps
1. Open Coffee options panel from category navigation.
2. Verify each option row includes coffee name text.
3. Verify each option row includes visible price text.
4. Scan rows quickly and confirm names and prices are aligned for readability.
5. Confirm empty/fallback behavior can be supported by content model when needed.

## Result
- All listed options show clear name and price values.
- Name and price alignment improves scanability.
- Data model supports fallback price labeling for missing values.
