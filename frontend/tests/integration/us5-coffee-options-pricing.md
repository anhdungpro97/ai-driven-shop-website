# US5 Validation - Coffee Item Details Display

## Steps
1. Open Coffee options full-screen view from category navigation.
2. Verify each option row includes coffee name text.
3. Verify each option row includes coffee image, visible price text, and order button.
4. Scan rows quickly and confirm names, images, prices, and actions are aligned for readability.
5. Confirm empty/fallback behavior can be supported by content model when needed.

## Result
- All listed options show clear name, image, price, and order action values.
- Row alignment improves scanability of details and action controls.
- Data model supports fallback price labeling for missing values.
